# AI Study Planner

## About the Project

AI Study Planner is a web-based application that generates a personalized study timetable based on the student's exam date, available study hours, selected units, and difficulty level.

## Features

- Personalized study timetable
- Exam date-based planning
- Difficulty-based study allocation
- Unit-wise study planning
- Available study hours management

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- Browser LocalStorage

## Project Structure

- `app.py` – Backend application
- `templates/` – HTML pages
- `static/` – CSS and JavaScript files

## How It Works

The student enters their exam details, available study hours, subjects/units, and difficulty level. The application processes the information and generates a personalized study timetable.
